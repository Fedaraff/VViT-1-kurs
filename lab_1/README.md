# Лабораторная работа №1: Работа с структурами данных, циклами и условными операторами в Python

### В данной лабораторной работе изучаем работу условного оператор if-else, и работу цикла.

В файле [num_1.py](num_1.py) мы, при помощи цикла, выводим все положительные числа от 1 до указанного.

В файле [num_2.py](num_2.py) мы, при помощи условного оператора if-else, проверяем какое из представленных чисел больше. 

Файл [Task_conditions.md](Task_conditions.md) содержит условие лабороторной работы.
