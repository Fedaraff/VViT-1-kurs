# Лабораторная работа №3: Работа с файлами в Python: открытие, чтение, запись, работа с исключениями


В файле [num_1.py](num_1.py) реализована программа, которая читает файл либо построчно, либо весь файл полностью

В файле [num_2.py](num_2.py) реализована программа, которая вносит в файл ``user_input.txt`` данные, заданные пользователем

В файле [num_3.py](num_3.py) модидифицированная программа из файла [num_1.py](num_1.py), которая в случае отсутствия файла выводит класс исключения *FileNotFoundError*.
