# Лабораторная работа №7: Работа с классами ч.3

В файле [num_1.py](num_1.py) 
1. Создан класс `Employee`, который содержит атрибуты, такие как `name` и `id` и метод `get_info()`, который возвращает базовую информацию о сотруднике.
2. Создан класс `Manager`, который наследуется от `Employee` и добавляет атрибут `department` и метод `manage()` символизирует управление проектами.
3. Создан класс `Technician`, который наследуется от `Employee` и добавляет атрибут `specialization` и метод `maintenance()` означающий выполнение технического обслуживания.
4. Создание класса `TechManager`, который наследует от `Manager` и `Technician`, комбинируя управленческие и технические навыки и добавляет методы, которые позволяют добавлять сотрудника в список подчиненных и выводить информацию о всех подчиненных сотрудниках

Файл [Task_conditions.md](Task_conditions.md) содержит условие лабораторной работы.
