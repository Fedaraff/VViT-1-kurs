# Лабораторная работа №2: Функции в Python и базовые алгоритмы

### В данной лабораторной работе пишем простые функции, учимся работать с аргументами функции и пишем функцию для решения алгоритмической задачи

В файле [num_1.py](num_1.py) мы пишем 3 простые функции, благодаря которым поймем механизм передачи аргументов функции и вывод результата.

В файле [num_2.py](num_2.py) мы пишем функцию с параметром по умолчанию и проверяем каким образом данный параметр будет выводится.

В файле [num_3.py](num_3.py) мы пишем алгоритм функции, который проверяет число на простоту и выводит соответствующий результат.

Файл [Task_conditions.md](Task_conditions.md) содержит условие лабороторной работы.
